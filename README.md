# CAD Portfolio

Готовый статический сайт для GitHub Pages: HTML, CSS, vanilla JavaScript. Сборка, npm и серверная часть не нужны.

## Публикация

Распакуйте ZIP. Добавьте содержимое папки в корень репозитория через Git или GitHub Desktop, сохраняя `assets` и `.nojekyll`. Из-за размера MP4 предпочтительнее Git/GitHub Desktop, а не загрузка через браузер.

Откройте **Settings → Pages → Deploy from a branch → main → /(root) → Save**. Все пути относительные, сайт работает из подпапки репозитория. [Официальная инструкция](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

Для локального просмотра откройте `index.html` или выполните из папки `python -m http.server 8000` и откройте `http://localhost:8000/`.

## Текущая компоновка

- Portfolio + полный Intro образуют один экран. Show more в Intro отсутствует.
- На компьютере каждый следующий раздел расположен по центру отдельного экрана, с пределом высоты 91svh. Соседние разделы не видны в установленной позиции. Один жест колеса ведёт к следующему экрану; Ctrl+wheel сохраняет масштабирование браузера.
- При входе в область просмотра разделы плавно появляются снизу вверх. При повторном возвращении анимация повторяется. При reduced motion она отключена.
- На телефоне — свободная прокрутка и раскрытие длинных описаний. У кнопки Revive чёрная граница.
- Cutter: заголовок на верхней грани плашки, отдельные интервалы между предложениями и отступ перед этапами разработки.
- Piñata: видео и рендер слева, описание и три миниатюры справа; на телефоне — описание, видео и четыре миниатюры. Используется исправленный GIF3.
- Revive: объект, вертикальный GIF4 без обрезки и дополнительные ракурсы справа. На телефоне медиа переходят в два ряда.
- Keyboard и LED содержат новые развёрнутые описания, основанные на тексте пользователя.
- Под цветными блоками есть тени сверху и снизу. Фон — единый CSS-градиент. Оранжевый и зелёный усилены относительно приглушённой версии.

## Две ленты в одном экране

Other и Reverse находятся в одном блоке прокрутки. Изображения обеих лент одинаковой высоты. Other движется вправо, Reverse — влево.

При наведении подпись скрывается, а карточка увеличивается на 25%, раздвигая соседние. В центральной области лента останавливается; зоны по краям (20% ширины окна) задают направление движения. На телефоне удерживание скрывает подпись и останавливает ленту, свайп перемещает её, отпускание возобновляет движение. Кнопок паузы нет. Подписи выровнены по нижней линии с одинаковым отступом.

В Other — 10 карточек, в Reverse — 11. Несколько ракурсов одного объекта объединены внутри одной HTML-карточки, без склейки или уменьшения исходных файлов. Все 20 новых PNG скопированы без перекодирования. Car CD-slot mount также заменён новым оригиналом PNG (873×716). Все первоначальные карточки галерей теперь используют предоставленные качественные изображения.

## Редактирование

- `index.html`: тексты и структура.
- `styles.css`: компоновка, цвета, шрифты, анимации.
- `script.js`: переключение экранов, видео, раскрытие текста, управление лентами.
- `captions.js`: подписи карточек; для режима без JavaScript также обновите соответствующий figcaption в HTML.
- `assets/images`: исходная графика, новые PNG и header.png.
- `assets/fonts`: полные локальные Montserrat и Bebas Neue Bold, лицензии.
- `assets/video`: четыре MP4, подготовленные для faststart без перекодирования. Контрольные суммы медиаданных — `integrity.json`.

В header.png уже присутствуют Portfolio и 2026. Имя, контакты, список программ и остальные тексты сайта — HTML. Видео имеют autoplay/muted/loop/playsinline и не имеют controls. Невидимые видео приостанавливаются; загрузка начинается рядом с экраном. Изображения лент подготавливаются перед началом движения. Внешних зависимостей шрифтов или библиотек нет.

`IMAGE-REPLACEMENT.md` содержит идентификаторы карточек. Проверки — в `VALIDATION.md`. Публикация на GitHub не выполнялась.
