# Проверка последней редакции

Проверено в локальном Chromium / Microsoft Edge на Windows через HTTP из подпапки проекта.

- Размеры: 1920×1080, 1280×720, 1024×600, 390×844 и 320×700. Горизонтального переполнения и ошибок JavaScript не обнаружено.
- Обложка с полным Intro: один экран, без Show more. После прокрутки Powercell выравнивается по вертикальному центру.
- Повторная анимация появления подтверждена измерениями: промежуточная opacity 0.38, смещение 34 px; в конце opacity 1 и смещение 0.
- Обе ленты одновременно помещаются в одном экране; высоты карточек совпадают (248 px на desktop, 155 px на мобильной проверке).
- Направления подтверждены изменением координат: Other вправо, Reverse влево.
- Масштаб карточки при наведении измерен как 1.250; соседние карточки сдвигаются. Подпись при наведении исчезает.
- Все новые PNG сохранены без изменения исходных файлов. Несколько изображений сгруппированы в HTML-мозаики.
- GIF4 (900×1080) воспроизводится и отображается без обрезки. Faststart не изменил медиаданные ни одного MP4.
- Revive, Cutter, Piñata и объединённые галереи проверены визуально. Мобильный Revive показывает два ряда медиа.

Сенсорные жесты проверены в эмуляции в предыдущей редакции; их обработчики сохранены. Физические устройства, Safari и опубликованный GitHub Pages не проверялись. Car CD-slot mount заменён предоставленным PNG 873×716; SHA-256 исходника и копии совпадает.


Latest layout verification: mobile 390x844 Keyboard and LED Show more/Show less controls expand and collapse successfully. Cover image uses contain to preserve its full width. Desktop 1440x900 Revive video retains 5:6 aspect ratio and meets the adjacent image grid with a zero-pixel gap. Screenshots visually reviewed.
